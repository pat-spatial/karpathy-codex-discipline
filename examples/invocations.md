# Invocation Examples

Use the full phrase when the task is risky:

```text
Use Karpathy skill: keep this surgical, state assumptions, define success criteria, and verify.
```

Short forms that should also be understandable:

```text
Use Karpathy skill on this.
```

```text
Use karpathy-codex-discipline for this refactor.
```

```text
Karpathy mode: no broad cleanup, no speculative abstractions, verify the fix.
```

For reviews:

```text
Review this with Karpathy skill. Prioritize bugs, scope creep, hidden assumptions, and missing verification.
```
